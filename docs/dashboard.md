# Zora Dashboard

!!! warning "Service discontinued"
    Zora Dashboard was discontinued on August 24, 2026. New users and new integrations are no longer accepted.
    This change applies only to the Dashboard. Zora OSS remains free and open source, with scan results available
    in the Kubernetes cluster through the Kubernetes API and `kubectl`.

For Zora OSS, use commands such as:

```shell
kubectl get vulnerabilities -n zora-system
kubectl get misconfigurations -n zora-system
```

The remainder of this page is retained as historical documentation for previous Dashboard integrations.
